# Design system

All 12 directions are bundled in `src/styles/tokens.css`; switch at runtime with `document.documentElement.dataset.theme` (direction-switcher recipe in the kit README).

- **Warm Editorial** (`warm-editorial`) - editorial. The Soma language. Warm paper, sunset amber, serif voice.
- **Ledger** (`ledger`) - corporate. Sharp financial. Cool paper, deep green, flat and compact.
- **Midnight** (`midnight`) - technical. Dark-first. Charcoal, electric cyan, glow shadows.
- **Kinfolk** (`kinfolk`) - organic. Organic paper. Cream, moss, soft radius, unhurried.
- **Ink & Coral** (`ink-coral`) - modern. Hard white, near-black, coral pop. Poster energy.
- **Nairobi Noon** (`nairobi-noon`) - warm. Warm sand, terracotta, relaxed. Kenyan daylight.
- **Slate & Lemon** (`slate-lemon`) - technical. Cool slate, gold lemon highlight, sharp. Dense data surfaces.
- **Porcelain** (`porcelain`) - minimal. Cool white, indigo, quiet. Nearly no chrome.
- **Terracotta Night** (`terracotta-night`) - warm. Dark warm. Ember orange on charcoal-brown.
- **Mint Ledger** (`mint-ledger`) - corporate. Teal on mint paper. Fresh, precise, compact.
- **Blueprint** (`blueprint`) - technical. Deep blue field, light ink, sharp. Schematic feel.
- **Playdate** (`playdate`) - playful. Violet pop, pill radius, shadows up. Consumer fun.

Generated by [uiforagents](https://github.com/peteretelej/uiforagents); the
committed `src/styles/tokens.css` is the source of truth. Regenerate with
the flow commands and commit the output.

## Adherence

`check` lints the configured HTML/CSS against the registry and reports -
never auto-corrects - three violation classes: raw hex colors, invalid or
missing `data-variant`, and tokens outside the copied items' `cssVars` and
this project's `src/styles/tokens.css`. Lint scope: `src/ui/**/*.html`, `src/ui/**/*.css`, `src/styles/**/*.css`.

## Flow

Config: `uiforagents.json`.

```sh
node ../uiforagents/scripts/uifa.mjs tokens
node ../uiforagents/scripts/uifa.mjs add
node ../uiforagents/scripts/uifa.mjs scaffold
node ../uiforagents/validation/check.mjs
```
